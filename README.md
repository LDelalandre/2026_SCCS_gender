# Women's status in preindustrial societies - a reanalysis

This projects uses data of the Standard Cross-Cultural Sample, accessible on [D-place](https://d-place.org/contributions/SCCS). The data is directly downloadable [on Zenodo](https://zenodo.org/records/17601873).

For reproducibility, consult the `sessionInfo.txt` file (which is the output of the `sessionInfo()` R function).
